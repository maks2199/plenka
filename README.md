# Плёнка

Игра-рефлексия для PowerPoint-пати из ваших фото за год или несколько лет.

Загружаете фото (файлы, папки, zip), переписку и треки. Приложение читает дату и место каждого кадра, нарезает ленту на события и собирает показ:

**интро → для каждого события: «угадай событие» по размытому коллажу → титул → сторис → вставки «Что было раньше?» и «Кто это написал?» → рефлексия → итоги в цифрах → таблица всех событий → финал**

Всё работает в браузере: фото никуда не отправляются. Проект (пережатые кадры, правки событий, переписка) хранится в IndexedDB и переживает перезагрузку страницы.

## Что умеет

- **Импорт:** JPG/PNG/WebP/HEIC, папки и zip (вложенные папки, перетаскивание), Telegram `result.json` и `messages.html`, WhatsApp `_chat.txt`, GPX-треки. Дубли пропускаются.
- **Дата кадра:** EXIF `DateTimeOriginal` → имя файла (`IMG_20250720_180211`, `IMG-20250720-WA0003`, `PXL_…`) → дата файла (можно выключить).
- **События:** новое событие после N календарных дней без фото (по умолчанию 1). Ручные правки: разрезать на кадре (`K`), склеить с предыдущим (`J`), разрезать по дням, исключить из игры. Правки хранятся по ключу кадра и переживают смену порога.
- **Название события:** своё, иначе имя папки или архива → праздник по дате → месяц и длительность.
- **Кадры:** сторис (`S`), коллаж (`C`), обложка (`O`), убрать (`X`); по умолчанию — равномерно по времени.
- **Итоги по смыслу:** события, дни вместе, км (GPX → геометки → вручную), ночи вне дома, точки на карте, сообщения, главный голос чата, счётчики фраз из чата, свои цифры, рекорды.
- **Показ:** полноэкранный плеер. `Space`/`→` — дальше или ответ, `←` — назад, `P` — пауза, `F` — полный экран, `M` — музыка, `Esc` — меню с переходом к событию.
- **Экспорт:** один `.html` со всеми кадрами (1280 px), открывается без приложения и без интернета.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # vitest: нарезка, парсеры чатов, даты, сборка показа
npm run build    # dist/ — статический сайт
```

Стек: Vite + React 18 + TypeScript, `exifr` (EXIF и GPS), `jszip`, `idb` (IndexedDB), `heic2any` (грузится лениво, только для HEIC).

## Устройство

```
src/
  lib/
    store.ts      состояние приложения, подписка для React, конфиг по умолчанию
    db.ts         IndexedDB: стор photos (по записи на кадр) и kv (конфиг, чат, треки, музыка)
    persist.ts    подъём проекта при старте, очистка, музыка
    importers.ts  файлы, zip, чаты, GPX → пережатые кадры (1600 px + миниатюра 360 px)
    image.ts      декодирование (HEIC через heic2any), ресайз, data URL
    chat.ts       парсеры Telegram JSON/HTML и WhatsApp
    events.ts     нарезка на события, названия, черновики вопросов, км, роли кадров
    metrics.ts    итоги и рекорды
    show.ts       сценарий показа (слайды) и превью сценария
    play.ts       запуск плеера и сборка HTML-экспорта
    actions.ts    действия редактора событий
    demo.ts       демо из нарисованных кадров (не сохраняется)
  player/runtime.js  плеер: самодостаточная функция без импортов,
                     её исходник через `?raw` целиком попадает в экспорт
  components/   экраны: Загрузка, События, Сценарий, Итоги
```

## Деплой

Workflow `.github/workflows/deploy.yml` прогоняет тесты, собирает и публикует сайт на GitHub Pages при пуше в `main`. Один раз включите в репозитории **Settings → Pages → Source: GitHub Actions**.
